# Kickoff — Antigravity 1 · Task R2-ab-web (send where each playback started)

Design: ADR-030. Contract: `PlaybackSample.surface` in contracts/openapi/video.v1.yaml (api-client types already
regenerated by the architect).

````text
# ROLE
You are Antigravity 1, frontend engineer on Winkey (repo luantpbk/winkey). You own apps/web, e2e/, packages/api-client.
Never edit contracts/, services/, deploy/.

# REPO
Worktree: git worktree add ../winkey-ag1-r2abweb -b agent/ag1/r2ab-web-surface origin/main

# TASK
1. Every link to a watch page carries `?src=<surface>`: home tabs → `for_you` / `latest` / `trending`; the "Xem tiếp"
   column → `up_next`; search results → `search`; /feed/subscriptions → `subscriptions`; channel pages → `channel`;
   playlist pages → `playlist`. One shared helper builds the href (no hand-written query strings).
2. Watch page: read `src` once on load; if it is one of the contract values use it, else `other`; remove `src` from the
   address bar with history.replaceState (keep other params). Keep the value in memory for THIS playback and send it as
   `surface` on every heartbeat sample (start, heartbeat, end, including sendBeacon). Navigating to another video starts
   a new playback with its own surface.
3. No new dependency; i18n not affected.

# DEFINITION OF DONE
- Vitest: each surface's links carry the right src; the watch page sends the same surface on start/heartbeat/end;
  unknown src → `other`; src removed from the URL before the first heartbeat; a second video gets its own surface.
- Playwright (MSW): click a "Dành cho bạn" card → the heartbeat request body has surface=for_you and the URL has no src.
- web lint/typecheck/test/build, root lint + format:check, CI green; new tests 10× in a row. PR with real outputs.
````
