## Hard rules

1. **Stay in your directories.** If you need a change elsewhere, open an issue and assign it to the owner.
2. **Contracts are law.** Implement `contracts/openapi/*.yaml` and `contracts/events/*.schema.json` exactly. Never edit them. If a contract is wrong or missing something, stop and open an issue labeled `contract-change` explaining why.
3. **Never write migrations.** Schema changes go through the architect (`db/migrations`).
4. **One task per branch and per PR.** Branch: `agent/<agent>/<task-id>-<slug>` (for example `agent/sonnet/v2-transcoder`). Open the PR against `main`. Never push to `main`, never force-push a shared branch, never merge your own PR.
5. **No secrets in git.** Config comes from environment variables only. Commit a `.env.example` with dummy values.
6. **Multi-arch.** Edge nodes are **arm64**. Every image must build for `linux/amd64,linux/arm64`, except `transcoder-nvenc` (amd64 only).
7. **Never skip, disable or weaken a test to get CI green.**
8. **One git worktree per agent — never share a working directory.** Two agents in one folder switch each
   other's branches, and commits land on the wrong branch (this happened on 2026-09-29). Create yours once:
   `git worktree add ../winkey-<agent> -b agent/<agent>/<task-id>-<slug> origin/main`.
   Before every commit, run `git branch --show-current` and confirm it is your branch.

## Definition of Done (every PR)

- Lint, typecheck and unit tests pass locally and in CI. New logic has tests.
- The service boots with `make dev` (once F3 lands) and exposes `/healthz` + `/readyz`.
- Logs are JSON; no tokens, passwords or emails in logs.
- A README in the service directory covers how to run, configure (env table) and test it.
- The PR description is the **Handoff Report** (template in `.github/pull_request_template.md`).

## Conventions (summary; the details are in docs/ARCHITECTURE.md §4 and ADR-010)

- IDs are UUIDv7 generated by the app. Timestamps are `timestamptz` and serialised as RFC 3339 UTC. JSON uses `snake_case`.
- Errors are RFC 9457 `application/problem+json` with a `code` field.
- Pagination uses an opaque `cursor`, and responses carry `next_cursor`.
- Identity: trust **only** `X-User-Id` / `X-User-Roles` set by the gateway. Never parse JWTs outside auth-svc.
- Domain events go through the **transactional outbox** (ADR-008). Never publish directly from a request handler.
- Go ≥ 1.24, `log/slog`, `pgx/v5`, `chi`, `aws-sdk-go-v2`, `nats.go/jetstream`, `testcontainers-go`.
- TypeScript: Node 22 LTS, strict mode, pnpm.
